BRERA STYLEBOOK
Version 1.2.0

A private, local-first visual reference library for AI workflows.

This is the current official BRERA Stylebook release. It uses the full BRERA editorial visual system with a larger, more readable typography scale across the complete interface.

QUICK START

1. Extract the complete ZIP file.
2. Open START-HERE.html.
3. Select OPEN BRERA STYLEBOOK, or open BRERA-STYLEBOOK-COMPLETE-GUIDE.html for the full walkthrough.
4. Explore the 9 included starter references in STYLES and UX, or add your own images.
5. Click an image to copy it, then paste it into ChatGPT or another compatible AI tool.

WHAT CHANGED IN 1.2.0

- New starter library embedded directly in the application.
- 9 included visual references available on first launch.
- Starter categories changed to STYLES and UX.
- Existing user libraries are preserved during upgrade; the old untouched starter set is migrated automatically.
- Backup export now includes embedded starter images, making exported backups self-contained.
- All existing Stylebook features and BRERA visual language preserved.

INCLUDED GUIDE

BRERA-STYLEBOOK-COMPLETE-GUIDE.html provides the complete step-by-step workflow: first launch, adding references, categories, search, favorites, copy-to-AI, backup/restore, troubleshooting and recommended usage.

MAIN FEATURES

- Local image upload and drag-and-drop.
- PNG, JPEG, WEBP, and GIF support.
- One-click image copy.
- Custom categories.
- Search and favourites.
- Three-column, five-column, and list views.
- Editable titles and categories.
- Local browser storage.
- Backup export and restore.

IMPORTANT

Your library is stored by the browser on the current device. Export a backup regularly, especially before clearing browser data, changing browser, or moving to another computer.

For the most reliable image-copy experience, use a current version of Google Chrome and open the extracted application directly, not inside a file preview.
