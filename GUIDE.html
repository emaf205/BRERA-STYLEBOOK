01 / First launch

Get started

BRERA Stylebook is a local visual-reference library. Version 1.2.0 opens with 9 starter references already organised into STYLES and UX.

Extract the ZIP.Keep the complete 01-CUSTOMER-FILES folder together. Do not move assets/demo-data.js away from the main HTML file.
Open START-HERE.html.Use a current version of Google Chrome for the most reliable image-copy experience.
Select “Open BRERA Stylebook”.The main library opens directly in your browser. No account is required.
Confirm the starter library.You should see 9 references and the category filters ALL, STYLES and UX.
Where your library livesYour references, categories and edits are stored by the browser on the current device. Treat exported backups as part of your normal workflow.
02 / Build the library

Add references

Use Stylebook for images you want to reuse as visual direction, UI inspiration, composition references, style cues, material references, photography direction, layouts or other AI inputs.

Click “+ Add reference”.The Add references panel opens.
Add your image files.Drag them onto the drop area or click the area to choose files. Supported formats are PNG, JPEG, WEBP and GIF. You can select multiple images in one batch.
Choose a category.All files in that batch are added to the selected category.
Click “Add to library”.Stylebook stores the images locally. Exact duplicate source files in the same library are skipped when their file signature matches.

Naming references

New items use the filename without its extension as the initial title. For a cleaner library, rename generic filenames such as IMG_2034 into useful intent-based names such as Editorial Grid / High Contrast.

03 / Organise

Find anything fast

Categories

Open the ☰ menu → Manage categories.You can add, rename and—when empty—delete categories.
Add a category.Enter a new name and select Add. Category names are normalised for consistency.
Rename a category.Select Rename. Existing references in that category move with the new name automatically.
Delete only empty categories.A category containing references cannot be deleted until its items are moved or deleted.

Edit a reference

Hover a reference and choose Edit. Change its title or category, then Save. The same panel also contains Delete.

Search, filters and favourites

  • Use the search field to narrow the library by title or category.
  • Select ALL, STYLES, UX or any category you create.
  • Select the star on a card to add or remove it from Favorites.
  • Use the Favorites control to show only starred items.

04 / Use with AI

Copy a reference

Choose the image you want.You can click the image itself or use the Copy button that appears on the card.
Wait for “Reference copied”.This confirms that Stylebook placed the image on the clipboard.
Switch to your AI tool.Paste the image into ChatGPT or another compatible AI interface.
Add your instruction.Tell the AI what to borrow from the reference: composition, visual language, spacing, material, mood, typography direction, hierarchy or another specific quality.
Better promptingA reference works best when paired with an explicit instruction. Instead of “make it like this”, state exactly what should be transferred and what should remain different.

Example workflow

1. Copy a reference from BRERA Stylebook. 2. Paste it into your AI chat. 3. Add: “Use this image only as a reference for layout density, typography scale and black/white contrast. Do not reproduce logos, copy or exact content.” 4. Add the actual task and constraints.
05 / Protect your work

Backup & restore

Because the working library is stored in browser storage, backups are essential before clearing browser data, changing browser, changing computer or performing a major library reorganisation.

Export a backup

Open ☰ → Export backup.
Save the JSON file somewhere safe.The filename includes the export date.
Keep periodic versions.Version 1.2.0 exports the embedded starter images too, so the backup is self-contained.

Restore a backup

Open ☰ → Restore backup.
Select a BRERA Stylebook JSON backup.
Choose Merge or Replace.Use the table below before deciding.
ModeWhat it doesUse it when
MergeKeeps the current library and imports the backup alongside it. Conflicting IDs are safely reassigned.You want to combine libraries or add content without removing current references.
ReplaceClears the current reference store, then restores the selected backup.The backup should become the complete library on this browser.
Before ReplaceIf the current library contains anything you may want later, export it first.
06 / Recommended system

A practical workflow

StyleBook becomes more useful when categories represent decisions you repeatedly make, not just folders you happen to have.

Start broad.Keep STYLES and UX, then add only categories you will actually reuse.
Name by purpose.Prefer titles that describe why the reference matters: Quiet Editorial Grid, Dense SaaS Dashboard, Warm Architectural Material.
Favorite the active set.Use Favorites as a temporary working board for the references relevant to the current project.
Copy one strong reference at a time.Be explicit about what the AI should extract from it.
Back up after meaningful changes.Especially after adding a large batch, reorganising categories or preparing a new computer/browser.

Suggested category ideas

Only create what fits your work. Examples: STYLES, UX, LAYOUTS, TYPOGRAPHY, MATERIALS, PHOTOGRAPHY, COLOR, ARCHITECTURE, SOCIAL, PRODUCT.

07 / Troubleshooting

Fix common issues

ProblemWhat to try
Image does not copyUse current Google Chrome; open the extracted HTML directly; keep the tab active; allow clipboard access if Chrome asks.
Starter images are missingConfirm BRERA-STYLEBOOK.html and the assets folder remain together. Do not open the HTML from inside a ZIP preview.
Old personal library appears instead of starter contentThis is expected when the browser already contains your BRERA library. Version 1.2.0 preserves existing user data rather than overwriting it.
Want the backup to become the whole libraryRestore it with Replace. Export the current library first if you might need it.
Cannot delete a categoryMove or delete its references first. Stylebook blocks deletion of non-empty categories.
Library disappeared after browser cleanupRestore your latest exported JSON backup. Browser storage can be removed when site/browser data is cleared.
08 / FAQ

Frequently asked

Does BRERA Stylebook require installation?

No traditional installer is required. Extract the package and open the HTML in a browser.

Does it require an account?

No account is required by the Stylebook application.

Where are my references stored?

The working library is stored in browser storage on the current device. Export backups regularly.

Which image formats can I add?

PNG, JPEG, WEBP and GIF.

Can I use my own categories?

Yes. Add and rename categories from Manage categories.

What is the difference between Merge and Replace?

Merge adds the backup to your current library; Replace clears the current reference store before restoring the backup.

Why does Stylebook include starter references?

They make the product useful immediately and demonstrate how STYLES and UX can be organised. You can edit, move or delete them as your own library evolves.

What should I back up?

Use Export backup. The generated JSON contains categories, reference metadata and the image data needed for restore.
