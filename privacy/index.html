Privacy

Privacy.

How the product stores its library and what the website contact form processes.

StyleBook library data

The current StyleBook application stores its working library in the browser on the current device. The product documentation recommends exporting a backup before clearing browser data, changing browsers or moving to another computer.

Contact form

If you submit the contact form, the site processes the fields you enter: name, email, reason, optional Gumroad purchase email and message. It also captures the source page and UTM parameters present in the URL so the owner can understand where enquiries originated.

Delivery depends on hosting. Netlify deployments use Netlify Forms. Compatible PHP hosting uses the configured mail destination. No destination email is embedded in the public package until configured by the site owner.

Theme preference

The site stores the light/dark theme preference in local browser storage.

External services

Purchase links open Gumroad. Author links may open LinkedIn or GitHub. Those services apply their own privacy practices.

Analytics and cookies

This release does not include a third-party analytics or advertising script. If analytics are added later, this notice should be updated before deployment.

Questions

Use the contact form for privacy questions.
